Thanks for wanting to contribute! A short guide to get started:

1. Fork the repository on GitHub and clone your fork:

```bash
git clone https://github.com/<you>/PokeRogouAnalyticsV2.git
cd PokeRogouAnalyticsV2
```

2. Install dependencies:

```bash
npm install
```

3. Build and test locally:

```bash
node scripts/generate-icons.mjs
npm run build
```

4. Make changes on a topic branch and open a PR with a clear description of the change.

Notes
-----
- Keep commits small and focused.
- Run `npm run typecheck` before opening a PR.
- Discuss large changes via an issue first so we can coordinate.

Thanks — maintainers
